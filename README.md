# Cybersecurity Automation Toolkit

## About Project

Cybersecurity Automation Toolkit is a Python project created to perform some basic cybersecurity tasks automatically.

The main purpose of this project is to understand how Python can be used in cybersecurity for system checking, port checking and file integrity monitoring.

## Features

- System Security Audit
- Localhost Port Checking
- File Integrity Monitoring
- SHA-256 Hashing
- Basic system information checking

## Technologies Used

- Python
- PyCharm
- Socket Programming
- SHA-256
- JSON

## Project Modules

### 1. System Security Audit

This module collects basic information about the computer such as:

- Operating System
- OS Version
- Computer Name
- Processor
- Python Version
- Available Disk Space

It also shows some basic security-related information.
